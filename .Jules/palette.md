## 2024-10-24 - Inline Transitions over Browser Alerts
**Learning:** Browser-native alerts break user flow and feel unpolished in modern web apps. Inline visual transitions (like icon checkmarks and temporary color changes) on buttons provide smooth, delightful, and non-disruptive feedback.
**Action:** Replace all native copy alerts with inline CSS/JS state transitions on target elements.

## 2024-10-24 - Icon-only Button Accessibility
**Learning:** Icon-only buttons are invisible to screen readers without descriptive ARIA labels.
**Action:** Always add `aria-label` attribute to elements containing only an icon without companion text.
