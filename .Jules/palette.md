## 2026-03-31 - Micro-UX and Accessibility Polish of Dashboard Header & Referral Copy Interaction
**Learning:** Avoid thread-blocking native elements like `alert()` in premium dark-themed fintech web applications to preserve visual consistency and continuous user interactions. Additionally, icon-only buttons require explicit `aria-label` attributes and focus-visible indicators for screen readers and keyboard navigation.
**Action:** Replace destructive alert/toast notifications with inline element state transitions (e.g., swapping a copy icon for a checkmark, altering the button background, and dynamically updating the `aria-label`). Always append `:focus-visible` styles to interactive `.icon-btn` styles to guarantee robust keyboard accessibility without visual clutter for pointer-device users.
