## 2025-02-18 - Overriding Cascading Icon Styles in Input Wrappers
**Learning:** In this application's custom design system, inputs are nested within an `.input-wrapper` container. The `.input-wrapper i` selector targets all child icons with absolute positioning (`left: 15px`). When introducing interactive elements inside the wrapper—such as a password toggle button containing its own Font Awesome icon—the CSS style leaks into the button's icon, resulting in broken layouts. Overriding these properties locally via inline styles (`position: static; transform: none; color: inherit;`) resolves the style leak gracefully without necessitating high-risk modifications to global CSS rules.
**Action:** Always apply style overrides (`position: static; transform: none; color: inherit;`) to icon elements embedded within custom buttons inside `.input-wrapper` containers to prevent layout breakage.
